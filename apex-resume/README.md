# 🏆 The Apex Resume Template

This is the flagship template of the repository. It is the exact format I used to secure a Software Engineering Internship at **SAP Labs**.

### Why this template works:
* **Single-File Simplicity:** The entire layout is contained within a single `apex_resume.tex` file. There are no complicated imports or multi-file setups to manage—just open the file, edit your text, and compile.
* **ATS Optimized:** Uses standard fonts and clear semantic headings so recruiter software can parse your data flawlessly without getting confused by heavy graphics or nested tables.

### How to use this template:

**Option 1: The Instant Overleaf Clone (Easiest Manual Way)**
Click the link below to open a Read-Only version of this project in Overleaf. Click `Menu` -> `Copy Project` to save it to your own account and start editing immediately.
👉 **[Clone in Overleaf](https://www.overleaf.com/read/jnwsqjbgsxzc#525100)**

**Option 2: Download the File**
Download the `apex_resume.tex` file in this folder. You can compile it locally using pdfLaTeX or upload it directly as a blank project in Overleaf.

**Option 3: The AI-Automated Way**
If you don't want to type LaTeX code at all, you can automatically generate this exact format by entering your details at **[CVInsight.me](https://www.cvinsight.me)**.
