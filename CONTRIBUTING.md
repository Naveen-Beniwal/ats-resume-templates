# Contributing to ATS Resume Templates

Thank you for your interest in contributing! We want to make this the go-to open-source collection of ATS-friendly resume templates for students and engineers.

## Ways to Contribute:
1. **Submit New Templates:** Have a battle-tested LaTeX, Typst, or Markdown resume format that passes ATS scans? Add it!
2. **Fix Formatting & Overleaf Bugs:** Improve margins, fix font package collisions, or optimize spacing in existing templates.
3. **Add Documentation:** Improve setup instructions, add compile instructions, or share ATS parsing tips.

## Contribution Guidelines:
1. **Fork the repo** and create a feature branch (`git checkout -b template/my-new-template`).
2. If adding a new template:
   - Place all files in a new folder inside `templates/` (e.g., `templates/quant-minimalist/`).
   - Include a clean, 1-page `.tex` file.
   - Include a high-resolution preview image (`preview.png`).
   - Verify that it compiles with zero warnings on Overleaf (pdfLaTeX or XeLaTeX).
3. Commit your changes and open a **Pull Request (PR)** with a brief description and preview screenshot.

All contributors will be featured in our README!
