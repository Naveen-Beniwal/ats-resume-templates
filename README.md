### 🛠️ How to use manually
If you prefer to edit the raw LaTeX files locally instead of using Overleaf or CVInsight:
1. Open the folders in this repo and download the `.tex` code for the template you want.
2. Compile using your preferred local LaTeX engine (e.g., pdfLaTeX, XeLaTeX).
